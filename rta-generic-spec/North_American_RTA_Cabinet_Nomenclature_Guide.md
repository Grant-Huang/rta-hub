# 北美 (USA/CAN) RTA 橱柜完整编码规范与产品规格指南 (Comprehensive Nomenclature & SKU Manual)

---

## 一、 编码结构与通用命名逻辑 (SKU Naming Principles)

北美 RTA（Ready-to-Assemble）橱柜体系的 SKU 命名遵循极其严密且模块化的逻辑。通用的编码结构由 **功能前缀 + 尺寸参数 + 功能/结构后缀 (+ 饰面代码)** 组成：

$$\text{SKU Formula: } \mathbf{[前缀/类型]} + \mathbf{[宽度]} + \mathbf{[高度]} + \mathbf{[深度(可选)]} + \mathbf{[功能/结构后缀]} + \mathbf{- [颜色/门板代号]}$$

### 标称尺寸与规则 (Dimensional Conventions)
1. **默认单位**：全部使用**英制英寸 (Inches)**。
2. **递增步长**：柜体宽度一般以 **3 英寸 (3")** 为基本步长递增（如 09, 12, 15, 18 ... 36, 39, 42）。
3. **默认深度**：
   - 地柜 (Base) 默认深度为 **24"**（SKU 中通常省略深度）。
   - 吊柜 (Wall) 默认深度为 **12"**（若为 15" 或 24" 深度，必须在编码中显式标出）。
   - 浴室柜 (Vanity) 默认深度为 **21"**（部分窄型为 18"）。
4. **默认高度**：
   - 地柜默认总高为 **34-1/2"**（包含 4-1/2" 的踢脚线 Toe Kick）。
   - 浴室柜默认高为 **34-1/2"**（Comfort Height）或 **31-1/2"**（Standard Height）。

## 四、 高柜与电器柜编码 (Tall & Appliance Cabinets - PC / U / OC)

高柜通用编码格式：`PC/U + 宽度 + 高度`（默认深度 24"）。高度需与吊柜加地柜的整体高度对齐（如 84" 对应 30" 吊柜，90" 对应 36" 吊柜，96" 对应 42" 吊柜）。

| **PC1884 / PC2484** | 储藏高柜 (Pantry / Utility) | 18"/24" | 84" | 24" | 上下对开门，内配 4-5 层活动隔板或可抽拉层板 (Roll-out Trays) |
| **PC3090 / U3090** | 双门宽食品高柜 | 30" | 90" | 24" | 对开门设计，匹配 36" 高度的吊柜系统 |
| **PC3696 / U3696** | 加大型通顶食品高柜 | 36" | 96" | 24" | 匹配 42" 吊柜，直达 9 英尺天花板 |
| **OC3084 / BOC3084** | 烤箱高柜 (Wall Oven Cabinet) | 30" | 84" | 24" | 中间预留开孔，用于嵌入式单/双烤箱或烤箱+微波炉组合 |

## 七、 常见门板与颜色代码后缀示例 (Finish & Door Style Suffixes)

在实际采购和下单中，SKU 末尾通常会附加颜色与门板样式的代码：

- **WW / WH** : White Shaker (白色摇头/框型门 - 最热销)
- **SG / GR** : Light/Dark Grey Shaker (灰色框型门)
- **ES / CH** : Espresso / Chocolate (深咖啡色/巧克力色实木)
- **AC / AG** : Antique White / Glaze (复古描边白)
- **NAV / NB** : Navy Blue (海蓝色)
- **NT / CO** : Natural Wood / Cinnamon Oak (原木色/肉桂橡木)

> **示例：**
> - **B30-WW** = 30" 宽地柜，白色 Shaker 门板。
> - **W3636-SG** = 36"x36" 吊柜，灰色 Shaker 门板。
> - **PC2490-NAV** = 24"x90" 高柜，海蓝色门板。
