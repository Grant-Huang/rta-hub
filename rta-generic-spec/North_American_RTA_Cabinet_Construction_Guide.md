# 北美 (USA/CAN) RTA 橱柜工艺、结构与材料规范手册 (Comprehensive Construction & Technical Manual)

---

## 一、 核心结构体系对比：美式面框柜 vs. 加式/欧式无框柜 (Framed vs. Frameless Construction)

在北美市场上，根据结构形态的不同，RTA 橱柜主要分为两大流派：**美式面框柜 (Framed Construction / American Style)** 与 **加式/欧式无框柜 (Frameless / European / Full-Access Style)**。两者在安装结构、门板覆盖方式及空间利用率上存在显著差异。

```
       美式面框 (Framed)                       欧式/加式无框 (Frameless)
   +-----------------------+               +-----------------------+
   |   [ 实木实体面框 ]     |               |  [ 裸露 3/4" 板材边缘 ]|
   |  +-----------------+  |               |  +-----------------+  |
   |  |   柜门 (Door)   |  |               |  |   柜门 (Door)   |  |
   |  +-----------------+  |               |  +-----------------+  |
   +-----------------------+               +-----------------------+
   * 门板贴挂于 1.5" 实木框架上               * 门板通过铰链直接挂在 3/4" 柜体侧板上
   * 结构刚性极强，适合传统/过渡风格           * 无框阻挡，内部使用空间提升 10%-15%
```

### 1. 详细特征对比表

| 对比维度 | 美式面框柜 (Framed Style) | 加式/欧式无框柜 (Frameless Style) |
| :--- | :--- | :--- |
| **主要流行区域** | 美国全境（占 70%+）、加拿大传统住宅区 | 加拿大主要都市区（温哥华/多伦多占高比例）、美西现代公寓 |
| **主体结构** | 柜体前沿装有 **1-1/2" $\times$ 3/4" 实木面框 (Face Frame)** | 无面框，柜体侧板边缘直接用 **0.5-1mm PVC/ABS 封边** |
| **柜体板厚** | 1/2" (12mm) 或 5/8" (15mm) 多层板 (Plywood) | **3/4" (18mm)** 多层板或高密度颗粒板 (Particle Board/MDF) |
| **门板挂载方式** | 铰链底座固定在 **实木面框的边缘** | 铰链底座直接通过膨胀塞螺丝固定在 **柜体侧板内侧** |
| **内部净开口空间** | 受 1.5" 面框侵占，收纳开口较缩减 | **完全通畅 (Full Access)**，抽屉与搁板宽度大 1.5"-2" |
| **组装方式 (RTA)** | **Cam-lock (偏心连接件)** 或 **Metal Clips (金属角码/扣件)** | **Dowel (木梢) + Confirmat Screws (三合一螺丝)** 或 **Cam-lock** |
| **外观风格** | 传统风格 (Traditional)、过渡风格 (Transitional/Shaker) | 极简现代 (Modern)、平板高光/木纹 (Slab / Flat Panel) |

## 二、 门板覆盖方式规范 (Door Overlay Styles)

门板与面框/箱体的相对位置决定了厨房的视觉缝隙与整体风格：

### 1. 全覆盖门板 (Full Overlay - 1-1/4" Overlay)
* **结构特点**：门板尺寸几乎完全盖住面框，周边仅露出 **1/4" (6mm)** 的面框边缘。
* **应用场景**：目前北美 RTA 橱柜市场（尤其是 Shaker 摇头门风格）的**最绝对主流**（占比 85% 以上），外观现代整洁且具备面框柜的强结构。

### 2. 半覆盖门板 (Partial / Standard Overlay - 1/2" Overlay)
* **结构特点**：门板仅覆盖面框 **1/2"**，相邻柜门之间会露出 **1" - 1.5"** 的实木面框。
* **应用场景**：北美经济型/出租房项目常用，成本较低，铰链免复杂微调。

### 3. 嵌入式门板 (Inset Doors)
* **结构特点**：门板完全平整地嵌入实木面框内部，门板与面框在同一个平面上。
* **工艺难度**：需要极高精度的加工与安装（四周留缝隙固定为 **3/32"**），温度湿度变化易卡门。RTA 领域极少采用，多用于高端定制柜。

## 三、 北美 RTA 主流材料与板材选用标准 (Material Specifications)

北美市场对 RTA 橱柜材料有非常明确的质量层级和环保环保认证要求（如 **CARB P2** 和 **TSCA Title VI** 扣减甲醛排放标准）。

```
                    ┌────────────────────────────────────────┐
                    │       北美 RTA 橱柜常见结构材料          │
                    └───────────────────┬────────────────────┘
                                        │
         ┌──────────────────────────────┼──────────────────────────────┐
         ▼                              ▼                              ▼
┌──────────────────┐          ┌──────────────────┐          ┌──────────────────┐
│   面框 / 门板    │          │  柜体箱体 (Box)  │          │   抽屉盒 (Drawer)│
├──────────────────┤          ├──────────────────┤          ├──────────────────┤
│• 枫木 (Maple)    │          │• 1/2" 多层板     │          │• 5/8" 实木燕尾榫 │
│• 橡木 (Oak)      │          │  (Plywood)       │          │  (Dovetail)      │
│• Birch / MDF 烤漆│          │• 5/8" / 3/4" 颗粒│          │• 质地清爽清漆    │
└──────────────────┘          └──────────────────┘          └──────────────────┘
```

### 1. 实木门板与面框常用木种 (Hardwood Species)
* **硬枫木 (Hard Maple)**: 纹理细腻，硬度高，抗撞击。是**白色/浅色喷漆 (Painted Cabinets)** 的最佳基材，不易胀缩变形。
* **黄桦木 (Yellow Birch)**: 物理特性接近枫木，成本略低。常用于**透明油漆/着色漆 (Stained Cabinets)**，具备天然木纹质感。
* **红橡木 (Red Oak)**: 具备强烈的山形木纹 (Cathedral Grain)，耐磨性极好，常用于传统美式大宅风格。
* **MDF (高密度纤维板)**: 专用于**单块模压/烤漆门板**的芯板。由于 MDF 无木纹且不受湿胀干缩影响，能有效防止烤漆门板拼接缝（Joint Line）开裂。

### 2. 箱体/柜身板材 (Cabinet Box Materials)
* **A 级胶合多层板 (Carb P2 Grade Plywood - 1/2" 或 5/8")**:
  - 北美优质 RTA 柜的标准配置。通常为 **5 层或 7 层** 交错压制的实木桦木/桉木多层板。
  - 外表贴紫外线固化清漆 (UV Finished Birch) 或与门板同色的三聚氰胺贴面板。
  - 优点：防潮性优异、握钉力强、不易弯曲变重。
* **高密度颗粒板 (Furniture Grade Particle Board - 5/8" 或 3/4")**:
  - 常用于低成本工程项目或工程型无框柜。
  - 必须包裹三聚氰胺贴面 (Melamine Paper) 并进行全封边处理。

### 3. 抽屉盒结构与工艺 (Drawer Box Construction)
* **美式标准实木燕尾榫抽屉 (Dovetail Solid Wood Drawer)**:
  - 侧板材质：**5/8" (16mm)** 实木橡木、枫木或桦木。
  - 接缝工艺：**4 角机器切割燕尾榫 (Dovetail Joinery)**，结构极其牢固。
  - 抽屉底板：**1/4" 或 3/8"** 多层板，嵌入式开槽固定 (Captured Bottom)。
  - 表面处理：高强度透明 UV 清漆涂层。

## 四、 五金件与连接结构规范 (Hardware & Mechanical Systems)

五金件的品质直接决定了 RTA 橱柜的使用寿命与手感，北美市场对 DTC 与 Blum 五金件认可度最高。

```
              底装式隐形阻尼滑轨                           美式面框缓冲铰链
        (Under-mount Soft-Close Slide)              (Face-Frame Soft-Close Hinge)
        
            +-------------------+                       +---------------+
           /  [ 抽屉底板 ]       /                      /  [ 面框边缘 ]  |
          +---------------------+                      +----+----------+
           || (隐形于底部)     ||                           │  / 阻尼液压缸
         [===========]       [===========]                  └──(  )---[门板]
```

### 1. 铰链系统 (Hinge Systems)
* **三维可调隐形缓冲铰链 (3D Adjustable Soft-Close Hinges)**:
  - 开门角度：标准为 **105° - 110°**；转角柜采用 **135° - 165°** 大角度铰链。
  - 微调维度：内置六角螺丝实现 **上下 ($\pm 2	ext{mm}$)、左右 ($\pm 1.5	ext{mm}$)、前后/深度 ($\pm 2	ext{mm}$)** 三向微调。
  - 集成阻尼：铰链杯内内置液压阻尼器 (Integrated Soft-Close Mechanism)，防止关门撞击。

### 2. 抽屉滑轨系统 (Drawer Slide Systems)
* **全拉出底装式软自闭滑轨 (Full-Extension Under-mount Soft-Close Slides)**:
  - **底装隐形 (Under-mount)**: 滑轨完全隐藏在抽屉底部，不占用侧向空间，美观且防尘。
  - **全拉出 (Full Extension)**: 抽屉可 100% 抽出，无死角拿取深处物品。
  - **承重标准**: 动态承重能力至少达到 **75 lbs (34 kg)**，重型抽屉达到 **100 lbs (45 kg)**。
  - **快速拆卸**: 前端配有快速释放卡扣 (Quick-Release Clips)，无需工具即可将抽屉盒从滑轨上卸下。

### 3. RTA 板件连接结构 (Assembly Mechanisms)
* **偏心扣件 / 偏心轮 (Cam-Lock & Pin System)**:
  - 最通用的 RTA 现场组装工具，仅需一把菲利普 (Philips) 十字螺丝刀即可完成柜体拼装。
* **金属 L 型角码 (Metal Clip System)**:
  - 美式面框柜特有组装方式。利用预先打好螺丝孔的金属角码将 1/2" 侧板与 1.5" 实木面框及后背板锁紧。
* **木梢与木工胶 (Wooden Dowels & Wood Glue)**:
  - 辅助定位与增强连接强度，随包附带专用的 PVA 木工白胶。

## 五、 北美 RTA 橱柜质量检测与认证标准 (Industry Standards)

出厂或进口至北美地区的 RTA 橱柜产品，通常需通过以下权威行业认证：

1. **KCMA 认证 (Kitchen Cabinet Manufacturers Association - ANSI/KCMA A161.1)**:
   - 北美橱柜行业的最核心质量标准。包含：
     - **门板挂重测试**: 门板悬挂 65 磅重物无下垂变形。
     - **抽屉循环测试**: 抽屉载重 15 磅/平方英尺，连续抽拉 **25,000 次** 无损坏。
     - **柜体承重测试**: 柜体内部搁板及整体载重 **50 磅/平方英尺** 持续 14 天。
     - **表面漆膜测试**: 抗热水、香醋、柑橘汁、酒精及洗洁精腐蚀能力。
2. **CARB Phase 2 / TSCA Title VI 环保认证**:
   - 限制人造板材（胶合板、MDF、颗粒板）的甲醛释放量：
     - 胶合板 (Plywood) 甲醛释放必须 $\le \mathbf{0.05 	ext{ ppm}}$。
     - MDF 高密度板甲醛释放必须 $\le \mathbf{0.11 	ext{ ppm}}$。
3. **FSC 认证 (Forest Stewardship Council)**:
   - 针对实木材料的森林可持续采伐管理认证，北美高档商业工程项目常强制要求。
