# 北美 (USA/CAN) RTA 橱柜核心尺寸规范与标准规格大全 (Comprehensive Cabinet Dimensions Manual)

---

## 一、 整体空间与建筑布局高度规范 (Overall Architectural Layout)

在北美厨房设计与安装中，所有橱柜与家电的尺寸都基于标准建筑层高及人性化工效学高度规划：

* **地柜标准完成面高度 (Finished Countertop Height)**: **36"**（914 mm）
  - 柜体高度 (Box Height): **34-1/2"**（876 mm）
  - 台面厚度 (Countertop Thickness): **1-1/2"**（38 mm，标准 3cm 石英石/花岗岩或 2cm 带加厚边）
  - 踢脚线高度/深度 (Toe Kick H x D): **4-1/2" H $\times$ 3" D**（114 mm $\times$ 76 mm）
* **地柜与吊柜之间悬空净高 (Backsplash Height / Clearance)**: **18"**（457 mm）
  - *例外：灶台/燃气灶上方至少留出 **24"-30"** 净高；微波炉抽油烟机组合柜 (OTR Microwave) 下方留出 **13"-16"**。*
* **吊柜底边安装基线 (Wall Cabinet Installation Baseline)**: 距完成地面 **54"**（1372 mm）
* **根据天花板高度 (Ceiling Height) 的吊柜与高柜匹配方案**:

| 天花板总高 (Ceiling Height) | 吊柜高度 (Wall Height) | 吊柜顶边高度 (Wall Top Line) | 高柜/食品柜高度 (Tall Cabinet Height) | 顶部留白与线条方案 (Top Finish Option) |
| :--- | :--- | :--- | :--- | :--- |
| **8 Feet (96")** | **30"** | 84" | **84"** | 留 12" 敞开空间或加高配 12" 顶角线 (Crown Molding) |
| **8 Feet (96")** | **36"** | 90" | **90"** | 留 6" 空隙贴标准 4"-6" Crown Molding 通顶 |
| **8.5 Feet (102")** | **36" / 42"** | 90" / 96" | **90" / 96"** | 搭配 6"-12" 组合线条与填缝板 (Scribe/Crown) |
| **9 Feet (108")** | **42"** | 96" | **96"** | 上方留 12" 空间，或采用“30"加12"双层叠装吊柜”通顶 |

* **标准高度**: **34-1/2"**（876 mm）。

## 七、 北美标准厨房家电预留留白净空 (Appliance Cutout Clearances)

橱柜设计与尺寸规划必须严格匹配北美标准家用电器尺寸：

1. **洗碗机 (Dishwasher Space)**:
   - 标准预留宽度: **24"** (610 mm) 净空。
   - 紧凑型/公寓型: **18"** (457 mm)。
   - 净高要求: **34.5"-35"**，直接落地安装在台面下方（不铺设橱柜底板）。
2. **灶具/独立式炉头 (Range / Stove Space)**:
   - 标准预留宽度: **30"** (762 mm) 或 **36"** (914 mm) 净空。
   - 豪华/半商业级炉头: **48"** 或 **60"**。
3. **标准冰箱预留位 (Refrigerator Space)**:
   - 标准预留宽度: **36"** (914 mm) 净空（两侧配合 1.5" 冰箱侧板后，实际橱柜开口为 **39"**）。
   - 预留高度: **70"-72"**；上方留出 12"-24" 高度的冰箱深吊柜。
4. **微波炉/油烟机预留位 (Over-The-Range / Range Hood)**:
   - 标准预留宽度: **30"** (762 mm) 或 **36"** (914 mm)。
   - 上方吊柜高度通常缩减为 **12", 15" 或 18"**，保证烟机离灶面至少有 **24"-30"** 的安全距离。
