# 北美 RTA 橱柜规格可替代性与模数化替换逻辑手册 (Cabinet Substitution Logic & Interchangeability Guide)

---

## 一、 替代核心原则与尺寸模数 (Substitution Core Principles)

在北美 RTA 橱柜（美式面框与加/欧式无框）的设计与现场安装中，当遇到某种特定规格的地柜（Base Cabinet）或门板缺货时，进行跨类别/跨尺寸替代需要遵循以下四大基本约束原则：

```
                    ┌────────────────────────────────────────┐
                    │        RTA 橱柜替换四大核心约束          │
                    └───────────────────┬────────────────────┘
                                        │
         ┌──────────────────────────────┼──────────────────────────────┐
         ▼                              ▼                              ▼
┌──────────────────┐          ┌──────────────────┐          ┌──────────────────┐
│   1. 深度差异    │          │   2. 高度补偿    │          │   3. 踢脚线与底座 │
├──────────────────┤          ├──────────────────┤          ├──────────────────┤
│地柜深度: 24"      │          │地柜标准高: 34.5" │          │地柜含 4.5" 踢脚线 │
│墙柜深度: 12"/15" │          │墙柜标准高: 30/36/│          │墙柜无底座，需现场 │
│必须加装背部支撑  │          │42"，需切裁/垫高  │          │脚座或自制木底座  │
└──────────────────┘          └──────────────────┘          └──────────────────┘
```

1. **深度对齐 (Depth Matching)**：
   * 标准地柜 (Base) 深度为 **24"**（含门 24.75"-25"）；标准墙柜 (Wall) 深度为 **12"** 或 **15"**。
   * **墙柜替代地柜**：必须加垫 **12" / 9" 的背部支撑框架 (Depth Extension Frame)**，以达到 24" 的台面支撑深度。
2. **高度补偿 (Height Alignment)**：
   * 地柜标准柜体高度为 **34.5"**（加上 1.5" 台面后为 36"）。
   * 欧式/加式无框柜的柜体纯高度通常为 **30"**，下方配合 **4.5" (115mm)** 调平板脚；美式地柜一体侧板含 4.5" 踢脚线。
   * 使用墙柜替代地柜时，最贴合的组合是 **30" 高墙柜 + 4.5" 可调地脚 (Adjustable Plastic Legs) 或自制踢脚线底座 (Toe-Kick Base)**，恰好达到 34.5" 柜体总高。
3. **结构承重与底座改造 (Base Construction)**：
   * 美式柜自带 **4.5" 高 $	imes$ 3" 深度** 的凹进踢脚线。墙柜或无自带底脚的无框柜用作地柜时，必须通过**现场加装可调塑料脚座**或 2x4 木方底座构建承重结构，再加挂踢脚线板 (Toe-Kick Skin)。

## 二、 墙柜 (Wall Cabinets) 替代 地柜 (Base Cabinets) 详细逻辑表

| 缺货/缺失地柜规格 | 建议替代墙柜规格 | 结构改造与安装调整逻辑 | 视觉与功能影响 |
| :--- | :--- | :--- | :--- |
| **B12** (12" 宽单门地柜) | **W1230** (12"宽 30"高墙柜) | 底部底板四角加装塑料可调地脚（调节至 4.5"）；背部加装 12" 支撑假墙/木方支撑至 24" 深。 | 无抽屉，全高单门（类似全高地柜 B12-F）。 |
| **B15** (15" 宽单门地柜) | **W1530** (15"宽 30"高墙柜) | 底部加装 4 个塑料地脚并用弹簧扣卡挂踢脚板，背部加垫支撑框架至 24" 深。 | 无上方抽屉，内部配 2 层活动搁板。 |
| **B18** (18" 宽单门地柜) | **W1830** (18"宽 30"高墙柜) | 同上，底部四角安装地脚，调节水平，背部垫深 12"。 | 失去顶部抽屉功能，收纳空间全为搁板。 |
| **B24** (24" 宽双门地柜) | **W2430** (24"宽 30"高墙柜) | 底部底板四角安装塑料脚（若承重较大可在中线加第 5 只脚）；背部垫深。 | 转换为 24" 宽全高双门地柜。 |
| **B30** (30" 宽双门地柜) | **W3030** (30"宽 30"高墙柜) | 底部加装 4-5 个可调地脚，背部加垫支撑框架至 24" 深。 | 替代 30" 地柜，适合做中岛背面浅柜或收纳柜。 |
| **B36** (36" 宽双门地柜) | **W3630** (36"宽 30"高墙柜) | 底部加装 5 个可调地脚（中间设支撑点），背部框架扩展至 24" 深度。 | 无抽屉，提供大容量搁板收纳。 |

## 三、 现代无框柜塑料可调脚 (Adjustable Plastic Cabinet Legs) 替代与转换逻辑

针对当前无框（Frameless / European Style）橱柜广泛采用塑料脚（如 Camar、Hafele、Titus 等品牌系统）的趋势，在墙柜代地柜、或原柜缺脚/无底座的情况下的技术替换方案如下：

```
                    ┌────────────────────────────────────────┐
                    │      塑料可调地脚 (Plastic Legs) 系统    │
                    └───────────────────┬────────────────────┘
                                        │
         ┌──────────────────────────────┼──────────────────────────────┐
         ▼                              ▼                              ▼
┌──────────────────┐          ┌──────────────────┐          ┌──────────────────┐
│   1. 螺丝/膨胀座 │          │   2. 伸缩可调腿  │          │   3. 踢脚板扣件  │
├──────────────────┤          ├──────────────────┤          ├──────────────────┤
│底座通过螺丝/盲孔 │          │螺纹套筒实现 3.5"- │          │扣件 (Toe-Kick    │
│固定在柜体底板下  │          │5.5" (90-140mm)   │          │Clips) 旋转卡挂在 │
│四角边距 35-50mm  │          │微调与现场找平    │          │塑料腿上，挂踢脚板│
└──────────────────┘          └──────────────────┘          └──────────────────┘
```

### 1. 塑料脚系统的四大核心优点
1. **防潮防水隔离**：柜体底板整体抬高 4.5"，避免地面积水直接泡烂多层板或颗粒板。
2. **高效找平能力**：北美不平整地面的微调范围可达 **3.5" 至 5.5" (90mm - 140mm)**，无需传统木楔子（Shims）。
3. **快速挂接踢脚板**：通过专门的**踢脚板塑料卡扣 (Toe-Kick Clips)** 直接旋转锁扣在塑料脚柱上，拆装维修极其方便。
4. **高承重性**：高强度 PP/ABS 工业塑料地脚单个动态承重可达 **300-500 lbs (150-230 kg)**。

### 2. 无自带脚地柜或墙柜改装塑料脚规范

当需要把无底座的墙柜改装成地柜，或原装脚缺失时，可采用通用第三方可调脚（如 Hafele 637.76.353 或 Camar 结构）进行转换：

#### 施工与固定步骤：
1. **底板加固与定位 (Base Reinforcement)**：
   * 若是用 1/2" 浅背墙柜改装地柜，底板较薄，需在底部四角内部或外部加垫一块 **3/4" 胶合板衬板 (Reinforcement Pad)**。
   * 脚座中心距离柜体边缘退缩：前沿退缩 **2.5" - 3"**（留出踢脚空间），侧边退缩 **1.5" - 2"**。
2. **座盖安装 (Base Plate Mounting)**：
   * 使用螺丝固定底座（通常每个脚座 4 颗 #8 $	imes$ 5/8" 自攻螺丝）锁定在柜体底板下方。
3. **调平与高度打定 (Leveling)**：
   * 将可调腿拧入底座，旋转套筒统一预设高度为 **4.5" (115mm)**。
   * 柜体就位后，使用长水平尺，用手或调整工具旋转腿身完成三维水平找平。
4. **卡挂踢脚板 (Toe-Kick Clip Attachment)**：
   * 在 1/4" 或 1/2" 踢脚线饰面板 (Toe-Kick Skin) 背面安装与脚座配套的**卡扣 (Toe-Kick Clips)**。
   * 将卡扣直接推入并卡紧在塑料脚柱上，完成饰封。

## 四、 门板与组件间互换与替代逻辑 (Door & Frame Interchangeability)

当特定尺寸门板缺货时，可通过**拼合、拆分或转角柜调配**实现替换：

```
                    ┌────────────────────────────────────────┐
                    │        门板与柜门替代三大组合机制         │
                    └───────────────────┬────────────────────┘
                                        │
         ┌──────────────────────────────┼──────────────────────────────┐
         ▼                              ▼                              ▼
┌──────────────────┐          ┌──────────────────┐          ┌──────────────────┐
│ 1. 双门变单门     │          │ 2. 高柜门板拆分   │          │ 3. 盲角柜拉伸调节 │
├──────────────────┤          ├──────────────────┤          ├──────────────────┤
│W30 (2张 15" 门)  │          │Pantry 84" 高柜    │          │BBC36-42 盲角地柜 │
│=> 2 个 W15 单门柜│          │=> W3030 + B30     │          │拉出 3"-6" 覆盖   │
│   组合拼接       │          │   上下门板组合   │          │非标宽度           │
└──────────────────┘          └──────────────────┘          └──────────────────┘
```

### 1. 宽双门柜 vs. 双窄单门柜 (Double-Door vs. Two Single-Door Cabinets)
* **替代逻辑**：
  * **1 个 W3030** (30" 宽双门墙柜，含 2 张 15" 门板) $\Longleftrightarrow$ **2 个 W1530** (15" 宽单门墙柜拼接)。
  * **1 个 B36** (36" 宽双门地柜，含 2 张 18" 门板) $\Longleftrightarrow$ **2 个 B18** (18" 宽单门地柜拼接)。
* **安装注意**：两个单门柜拼合时，需用 **Face-Frame Clamp (面框夹)** 夹紧后使用 1-1/4" 螺丝从侧面相互锁紧，并加装 1/4" 整体后盖板。

### 2. 高柜 (Pantry/Tall Cabinet) 与 墙柜+地柜 组合互换
* **替代原理**：
  * **高柜标准尺寸**：深 24"，高 84" / 90" / 96"。
  * **替代方案**：可以使用 **30" / 36" / 42" 墙柜 + 34.5" 地柜 + 延伸侧板 (Skin Panel)** 组合叠放。
* **替换公式**：
  * **84" 高柜 (PC1884)** $\Longleftrightarrow$ **18" 地柜 (B18)** + **30" 高墙柜 (W1830)** + **19.5" 高墙柜 (W1820)**（或直接上加 4.5" 顶胶板与底座）。

### 3. 盲角地柜 (Blind Base Cabinet) 的宽度弹性拉伸替换
* **替代原理**：
  * **BBC36-42**（盲角地柜）实际柜体宽度通常为 36"，但可以通过从墙角**向外拉出 3" 至 6"**，充当 39"、40" 或 42" 盲角地柜使用。
* **应用场景**：当特定宽度的盲角柜（如 BBC42）缺货时，用 **BBC36** 从角墙偏移 6" 安装，搭配填缝板 (Filler Panel) 即可完美替代。

## 五、 抽屉柜与特殊柜的跨类替代 (Drawer & Specialty Cabinets)

### 1. 3抽地柜 (3DB - 3-Drawer Base) 替代标准地柜 (B-Series)
* **替代逻辑**：当 **B24** 缺货时，可用 **3DB24** 替代。
* **优缺点**：3DB 成本高 20%-30%，但使用便利性极大幅度提升。对于客户而言是“免费升级/溢价升级”的替代选项。

### 2. 水槽柜 (Sink Base - SB) 与 标准地柜 (Base - B) 互换
* **地柜 (B) 替 水槽柜 (SB)**：
  * 拆除 B 柜内部的顶部交叉拉条/搁板，将顶部抽屉面板用 **假抽屉扣件 (False Front Clips)** 固定在面框上，即可将 B30/B36 改造为 SB30/SB36。
* **水槽柜 (SB) 替 地柜 (B)**：
  * 将水槽柜假抽屉面更换为功能性抽屉（需要现场订制抽屉盒与滑轨），内部加装搁板。

## 六、 现场替代施工与技术调整规范 (Field Adjustment Specs)

在利用墙柜或不匹配规格组件进行现场替代时，需严格执行以下施工规范：

1. **深度垫空框架构建 (Back-Framing for Shallow Cabinets)**：
   * 墙柜（12"深）用作地柜（24"深）时，必须在柜体后方用 **2x4 龙骨（实寸 1.5" $	imes$ 3.5"）或 3/4" 胶合板** 搭建梯形撑框架。
   * 台面重力（如石英石/花岗岩）必须直接通过背部框架或地脚垂直传导至地面，严禁悬空台面超过 **2"**。

2. **踢脚线封边 (Toe-Kick Skinting)**：
   * 所有由墙柜或塑料脚地柜改造的底座，前沿必须贴上 **1/4" 厚度 $	imes$ 4.5" 高度** 的配套饰面踢脚线板 (Toe-Kick Skin)，并利用塑料地脚卡扣锁紧。

3. **填缝板 (Filler) 与 覆盖微调 (Overlay Adjustment)**：
   * 当使用两组窄柜拼合替代宽柜时，面框缝隙需控制在 **1/32"** 以内。美式面框柜必须在拼合处使用 **木工胶 + 埋头螺丝** 锁紧。
